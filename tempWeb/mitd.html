Monsters in the Dark

Monsters in the Dark is a 2D platformer game developed by BoundlessBox Studio. The game is set in a dark and mysterious world where the player must navigate through various levels, avoiding obstacles and enemies along the way. Monsters in the Dark features a unique art style and challenging gameplay that will keep players entertained for hours on end. The game is currently in development and is set to be released in 2026.
